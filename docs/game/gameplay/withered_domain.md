# 枯萎之都

枯萎之都是零号空洞的探索玩法。玩家选择区域和难度、配置队员后进入分层探索，在途中处理事件与战斗，取得调查奖励。入口、难度和编队布局见 [手柄画面](../screens/withered_domain.md)。

区域包含资质考核、旧都列车、施工废墟、巨厦遗骸与枯败花圃。各区域的可选难度不同；实拍旧都列车包含外围、前线、内部、腹地、核心，施工废墟从前线开始。选关页同时显示调查点数、推荐等级和属性。

队伍有领队、队员和候补槽，下排未填写不会自动使上排队伍失效。进入本次调查时只有领队在场，后续可通过呼叫增援接应已有队员，并选择入队位置。探索中的商人、休息区和业绩考察点属于不同事件。

本次实拍中，假面研究者提供承受侵蚀后选择鸣徽的交易；「鸣徽厌性」使部分卡槽变为不可选择的「不可触碰之物」。这种占位不代表 OCR 漏识别，也不能作为鸣徽参与优先级选择。事件可能连续提供两次鸣徽选择。

商店的鸣徽交易消耗本次调查中的齿轮硬币，购买立即扣款并显示取得的鸣徽。本次实拍花费 1000 齿轮硬币取得「决斗·称手板砖」，余额从 1823 变为 823。

施工废墟内部的实拍中，前进后旧排或旧列会消失，镜头随剩余格子重新居中。第一段末尾仅剩当前位置和商人；进入商人格后同一层展开新的多排区域，左上仍为 1/3，不能把它计为进入第二层。画面见 `quick-last-tile.webp`，上一尾段见 `quick-fourth-map-failure.webp`。
