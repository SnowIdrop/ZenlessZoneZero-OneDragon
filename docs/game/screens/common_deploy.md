# 通用出战

副本准备页按「下一步」后进入编队界面。手柄版用 A 打开当前角色槽，X 打开预备编队，Start 提交出战，B 返回准备页。

三人编队页底部有「预备编队」。三个角色槽均为空时，各显示 `EMPTY`，中央显示 `SELECT`。此时按出战不能开始战斗；不能把提示弹窗或按钮暂时消失当作加载完成。

枯萎之都的旧版六人编队页底部是「战斗设置」，下排为候补，即使三个候补槽均为 EMPTY，上排队伍仍可出战，见 [枯萎之都](withered_domain.md)。空队伍判断仅适用于已确认的三人编队页。

`common_deploy.yml` 保留通用下一步、出战和确认区域。手柄空槽文字区域为 `手柄-队员槽`，不作为全局画面标识。当前留档只覆盖空队伍子态，已配置队伍和角色选择列表待补。
