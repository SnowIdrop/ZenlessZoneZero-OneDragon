# 菜单(主界面)

## 何时出现
在大世界打开菜单后出现。手柄 Start 打开，B 返回大世界。

## 可交互元素(对应 screen_info/menu.yml 的 area)
底部包含邮件、活动、丽都城募等横向入口。手柄左右方向键切换黄色矩形选中框，A 进入当前项。列表移动时入口的横坐标会改变，应以名称重新定位。

`手柄-底部选择` 覆盖这组入口，避免把其他位置的黄色装饰认成焦点。已实测从菜单进入邮件和丽都城募。

## 备注
手柄界面和鼠标界面的按钮提示不同。图片中的“发送按键”和后续页面出现必须分别核对，不能只凭输入函数返回值判定进入成功。
