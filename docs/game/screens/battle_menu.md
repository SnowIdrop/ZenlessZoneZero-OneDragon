# 战斗菜单

战斗中按 Start 打开暂停菜单，顶部为战况、设置页签。底部手柄提示依次包含 X 重新开始、Y 退出战斗、A 选择、B 返回。

按 X 后显示「是否重新开始战斗？」弹窗，右侧黄色确认按钮默认获得焦点；下方 A 选择。确认会重新加载当前战斗。对应截图：`screens/战斗-菜单/lost-restart-popup.webp`。

按 Y 后显示「是否确认退出战斗？」弹窗，同样使用右侧确认焦点与 A。迷失之地中退出会进入挑战结果。对应截图：`screens/战斗-菜单/lost-exit-popup.webp`。

已有 `按钮-战况` 用于辨认菜单；手柄布局用 `手柄-重开按键`、`手柄-重新开始`。确认框用 `手柄-重开提示`、`手柄-确认按键`，确认目标沿用 `按钮-退出战斗-确认` 的位置。
